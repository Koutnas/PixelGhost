Použité importy a důvod jejich použití:

hashlib - je standartní knihovna pro různé hashe nemyslím si že by se mělo něco instalovat ale kdo ví

numpy - knihovna pro práci s velkýmy n-dimenzionálními poli, je značně rychlejší než standartní list v pythonu plus má vlastní funkcionality jako např. random (pip install numpy)

opencv2 - knihovna pro práci s obrazem používá se i pro detekci objektů ale to je vedlejší, její hlavní funkcionalita je převádění obrazu do 3 dimenzionálních matic v numpy (toto se děje automaticky) a následné ukládání 3d matic zpět do obrazu (pip install opencv-python)
